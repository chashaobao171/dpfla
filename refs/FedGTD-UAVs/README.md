## 它做了什么

- **联邦迁移学习（FTL）**：集中式预训练（公开数据）+ 联邦微调**稀疏参数子集**；声称在严重 non-IID 下保持 >98% 性能。
- **自研检测器**：SPD-Conv 骨干 + GCNet 注意力（**不是 YOLOv8**）。
- **报告结果**：VisDrone2019 `mAP@0.5 = 44.2%`（声称比 YOLOv8s 高 12.1%）、217 FPS。
