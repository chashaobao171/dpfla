# MEMORY/chatlog/ — 会话纪要

## 为什么存在

Trae 的**聊天记录不跨主机共享**（存在客户端侧）。换主机后，新会话读不到上一次对话的上下文。
本目录把每次会话的**要点纪要**写进 git 仓库，随 `git pull` 一起同步 → **换主机后可无缝接续**。

## 约定

- **一文一会话**，命名 `YYYY-MM-DD_<主题>.md`（用会话**起始**日期）
- 只记**目标 / 结论 / 决策 / 踩坑与纠正 / 产出 / 下一步**，**不抄逐字对话**
- **不替代** `01_Facts.md`（实测数据）与 `04_Retracted.md`（已证伪结论）——那两份仍是唯一事实源；有冲突以它们为准
- 会话结束时（或用户要求时）由 AI 追加一篇；用户也可自行补写
