## 二、关键结论

1. **★ 里程碑：32% 目标达成（2026-10-10）**
   `1024 分辨率 + BS=32 + AMP` → **R7 = 32.09%（首破目标），R15 = 35.92%**，R11–R15 稳定在 35.0–35.9% 已收敛。
   对照 640 基线（R26-33 ≈ 23.7%）→ **+12 个百分点**。全程**只改训练配置，未动聚合/DPFLA**。

2. **最可能的主因是分辨率**（VisDrone 全是小目标，640 把原图缩 2–3 倍）。
   ⚠️ 但**非纯单变量**（同改 batch 64→32、AMP 关→开），需补 `640 + BS=32 + AMP` 对照臂才能定论。

3. **AMP 是 1024 能跑起来的前提**：纯 fp32 下 BS=64 第 1 个 batch OOM、BS=32 也在 backward OOM（31.3GB/32GB）；
   开 AMP 后 24GB 稳定。

4. **"换聚合模型"是错误方向**：FedAIoT 源码里 `server_momentum` 被丢弃、实际 `server_lr=1` ⇒ **等价于纯 FedAvg**（见 `04_Retracted.md` R1）。
   真正可动的是**训练配方**。

5. **训练循环原生化**：前人两条路——FLYOLO 直接用 `model.train()`；**FedAIoT = 自写循环 + ultralytics 组件**（DetectionModel / Loss / YOLODataset.collate + AMP + warmup + cosine），后者更贴合本项目。
